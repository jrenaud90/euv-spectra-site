Instructions

  1. Add new data: Choose the target collection, leave the mode set to append, upload a JSON file, then click Load Data. New documents are inserted without clearing the existing collection.
  2. Replace current data: Choose the target collection, change the mode to replace, type REPLACE in the confirmation box, then click Load Data. This clears the collection before inserting the uploaded documents.
  3. Delete data: Use the Delete Data form below Load Data. Pick either delete all, which requires typing the collection name exactly, or delete matching documents with a Mongo-style JSON filter. Use the download buttons first if you want a backup copy.
