PEGASUS API

The PEGASUS API exposes the same catalog lookup, flux-processing, and model-selection steps used by the web tool.

Response format

Successful requests return HTTP 200 with the following JSON envelope:

{
  "ok": true,
  "data": { ... }
}

Validation and lookup failures return structured errors with an HTTP status such as 400 or 404:

{
  "ok": false,
  "error": {
    "code": "missing_argument",
    "field": "name",
    "message": "name is required."
  }
}

Numeric inputs must be parseable as floats. Coordinate lookups expect ICRS sexagesimal input, for example 09h14m22.00s+52d41m00.68s.

Core lookup endpoints

Endpoint Required query parameters Returns
/api/get_parameters_by_name name Stellar parameters, coordinates, proper motion data, and GALEX fluxes.
/api/get_parameters_by_position position Same payload as the name lookup, seeded from coordinates instead of a target name.
/api/get_galex_obs_time star_name The earliest matching GALEX observation time.

Flux-processing endpoints

Endpoint Required query parameters Returns
/api/convert_microjanskies_to_flux At least one of fuv or nuv Converted GALEX flux densities and propagated errors when *_err values are supplied.
/api/scale_galex_flux dist, rad Surface scaling factor plus any supplied FUV/NUV values scaled to the stellar surface.
/api/get_matching_photosphere_model teff, logg, mass The nearest photosphere model metadata.
/api/subtract_photospheric_flux At least one matching pair of fuv/photo_fuv or nuv/photo_nuv Photosphere-subtracted fluxes and propagated errors.
/api/convert_scale_photosphere_subtract_galex_fluxes teff, logg, mass, dist, rad, and at least one of fuv or nuv Combined photosphere lookup, scaling, and processed GALEX fluxes.

Model-selection endpoints

Endpoint Required query parameters Returns
/api/get_matching_subtype teff, logg, mass The closest PEGASUS subtype for the stellar parameters.
/api/get_models_in_limits subtype, fuv, fuv_err, nuv, nuv_err Models whose fluxes fall within the provided GALEX error bounds.
/api/get_models_by_chi_squared subtype, fuv, nuv Models sorted by chi-squared distance from the supplied fluxes.
/api/get_models_by_weighted_fuv subtype, fuv, nuv Models ranked similarly to chi-squared search with stronger FUV weighting.
/api/get_models_by_flux_ratio subtype, fuv, nuv Models ranked by the agreement between observed and model FUV/NUV ratios.
/api/get_model_data fits_filename Wavelength and flux arrays from an available FITS file.

Example requests

GET /apps/pegasus/api/get_parameters_by_name?name=GJ%20338%20B
GET /apps/pegasus/api/convert_scale_photosphere_subtract_galex_fluxes?fuv=55.76&fuv_err=8.7&nuv=1002.16&nuv_err=14.88&dist=6.33256&rad=0.58&teff=4014.0&logg=4.68&mass=0.64
GET /apps/pegasus/api/get_models_by_chi_squared?subtype=M0&fuv=167.64971644316745&nuv=1219.2948859922221
